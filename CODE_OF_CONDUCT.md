# Code of Conduct

This project welcomes contributions from anyone. In issues, pull requests,
and discussions:

- Be respectful. Disagree with ideas, not people.
- Assume good faith.
- Harassment, personal attacks, and discriminatory language aren't tolerated.

The maintainer will remove comments, close issues/PRs, or block contributors
who violate this. To report a concern, use the contact route in
[SECURITY.md](SECURITY.md).

Adapted from the [Contributor Covenant](https://www.contributor-covenant.org/).
