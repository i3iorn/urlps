# urlps 2.0.0

Release date: 2026-10-19

## Highlights

A major release making the public API honest and reachable, with extensive
security hardening, new CLI, audit management, query accessors, and RFC 3986
resolution support.

## Breaking Changes

- The public API is now honest and reachable (decomposed modules, correct exports).

## Added

- `.rgignore` for search hygiene.
- `urlps` CLI entry point.
- Canonical form validation.
- Clear functionality to phishing database.
- Credential leakage detection.
- Dangerous port validation with override flag.
- DNS rate limiting and phishing database configuration constants.
- Enhanced Punycode/IDN validation.
- Fail-open configuration for DNS connection errors.
- `get_query_param()` / `get_query_param_all()` accessors.
- IPv6 zone identifier validation.
- JSON schema for audit events.
- Parser confusion attack detection.
- `pytest-cov` coverage reporting.
- Python 3.14 support.
- Query parameter injection detection.
- RFC 3986 Section 5 reference resolution (`urlps.join()`).
- Unicode normalization before validation.
- DNS rate limiter configuration validation.
- `URLPS_PHISHING_DATABASE_URL` environment override.
- Audit manager integration and structured audit callbacks.

## Fixed

- Pre-commit check fixes.
- CLI non-printable output escaping / C1 control character rejection.
- Compatibility with 1.1.4 `SecurityPolicy` argument order and 1.2.0 limiter APIs.
- Docstring corrections.
- Maximum path length test correction.
- Release-please tag format and spurious 2.0.0 revert.
- Scheme detection and phishing-db retry storm.
- Stale packaging metadata URLs.
- Bracketed host test correction.
- Query length maximum enforcement.
- RFC 3986 path normalization.
- Property-based round-trip tests under strict default.
- CI Python version matrix quote fixes.
- Unicode Script table regeneration.
- Security fixes for SSRF, derived URLs, credentials in logs, DNS timeouts,
  address rules, host validation, and protocol-level checks.
- URL comparison restoration.

## Changed

- Regex dependency bumped (2024.11.6 → 2026.7.19 → 2026.9.29).
- Cache diagnostics registration.
- Module decomposition (`url.py`, `__init__.py` split into focused modules).
- Policy presets derived from marked fields.
- Redaction module extraction; legacy `url_checks` helpers deprecated.
- Package renamed from `urlp` to `urlps`.
- Import path alignment with `src`-layout.
- `URL` component/context held as two stateless values.
