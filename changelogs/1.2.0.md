# urlps 1.2.0

Release date: 2026-10-02

## Added

- **security:** connect-time SSRF guard; drop the no-op DNS verification connect.

## Fixed

- **cli:** escape non-printable output; reject C1 control characters.
- **security:** accept only standard schemes unless `allow_custom_scheme`.
- **security:** bound the memory caches can pin with hostile input.
- **security:** cache DNS resolutions; isolate injected limiters; bound DNS time.
- **security:** derived URLs must mean what their string means.
- **security:** keep credentials and tokens out of exceptions and logs.
- **security:** never let a DNS attempt's timeout exceed the deadline.
- **security:** refresh, match subdomains, and optionally pin/fail closed on the phishing feed.
- **security:** treat every non-global address as internal; add address rules.
- **security:** validate the host the parser produced, not a re-parse.
