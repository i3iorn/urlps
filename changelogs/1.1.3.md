# urlps 1.1.3

Release date: 2026-09-13

## Highlights

A maintenance release: it lands query-parameter accessors, a CLI entry
point, Python 3.14 support, and SBOM generation that had accumulated on
`master` since 1.1.0 but were never released, and removes CI infrastructure
tied to a branch-protection rule that's no longer in effect.

## Added

- **`URL.get_query_param()` / `get_query_param_all()`.** Reads a single
  query parameter's first value (or `None`/a default if absent) or all of
  its values in order, without unpacking `query_params()` for the common
  single-key case.
- **`urlps` CLI.** A `urlps` command-line entry point for checking a URL's
  parse/validation result from the shell.
- **Python 3.14 support.** Added to the tested and declared-supported
  version matrix.
- **SBOM generation in CI.** Every build now generates a CycloneDX SBOM
  (`urlps-sbom.json`), uploaded as a build artifact alongside the sdist and
  wheel.

## Fixed

- Added a regression test pinning `dns_rate_limiter` identity through
  `resolve_security_policy`'s caching layer, so a future field added to
  `SecurityPolicy` can't silently reintroduce rate-limiter
  cross-contamination between differently-configured callers.

## Changed

- Bumped the `regex` dev dependency (generator-only; not a runtime
  dependency of `urlps` itself) to 2026.7.19.
- Removed `.github/workflows/only-dev-to-main.yml`. The "only `dev` can
  merge into `master`" restriction it enforced has been superseded by
  GitHub branch protection settings managed directly on the repository.
